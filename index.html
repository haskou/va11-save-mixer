        INSTRUCTIONS
        

    
        
      
        
        
        0. Before anything else
        
        
          
          
        • You need a PS Vita running HENkaku (h-encore, Enso…) and VitaShell.
          • 
          
        • Back up your saves on both sides before touching anything.
          • 
          
        • You must have saved at least once on the Vita: the converter uses that file as its base.
          • 
          
        • Close the game before copying files (on the Vita: press PS and peel off the LiveArea page).
          • 
        
        
      
        
    
        

    
        
      
        
        
        1. Where the PC saves live
        
        
        
          
        Windows%LOCALAPPDATA%\VA_11_Hall_A\saves
        
          
        macOS~/Library/Application Support/com.yoyogames.macyoyorunner/saves
        
          
        Linux~/.config/VA_11_Hall_A/saves (lowercase names)
        
        
        
        
        Each slot is a Record of Waifu Wars[N].txt (N = 1–24). Waifu Preferences.txt holds your settings and is not converted.
        
      
        
    
        

    
        
      
        
        
        2. Getting savefile.sav off the Vita
        
        
          
          
        1. In VitaShell, go to ux0:user/00/savedata/.
          2. 
          
        2. Find the game's folder: PCSB01166 for the European release; other regions use a different ID. If unsure, open sce_sys/param.sfo inside the folder: VitaShell shows the game title.
          3. 
          
        3. Backup: copy the whole folder (△ → Copy) and paste it somewhere like ux0:data/.
          4. 
          
        4. Highlight the game folder and press △ → Open decrypted.
          5. 
          
        5. On savefile.sav: △ → Copy. Go to ux0:data/ and △ → Paste.
          6. 
          
        6. Move ux0:data/savefile.sav to your computer (VitaShell FTP with SELECT, or USB).
          7. 
        
        
      
        
    
        

    
        
      
        
        
        3. Recipe: PC ➜ Vita
        
        
          
          
        1. Up top, in PC ➜ VITA, add the Record of Waifu Wars[N].txt files and the Vita's decrypted savefile.sav.
          2. 
          
        2. Hit MIX!. The table shows which Vita slot each save lands in. By default PC slot N goes to Vita slot N; if that slot was taken, the Vita save moves to a free one.
          3. 
          
        3. Download the new savefile.sav and copy it to ux0:data/ on the Vita.
          4. 
          
        4. In VitaShell: △ → Copy on that file, go to ux0:user/00/savedata/, highlight the game folder, △ → Open decrypted and △ → Paste (overwrite).
          5. 
          
        5. Start the game and load your save.
          6. 
        
        
      
        
    
        

    
        
      
        
        
        4. Recipe: Vita ➜ PC
        
        
          
          
        1. In VITA ➜ PC, add the decrypted savefile.sav and hit MIX!.
          2. 
          
        2. Download the ZIP (or the single files) and unzip it into the PC saves folder with the game closed. Files with the same name get replaced.
          3. 
          
        3. On Linux, tick lowercase file names.
          4. 
          
        4. If you use Steam Cloud and the game reports a sync conflict on launch, pick the local files.
          5. 
        
        
      
        
    
        

    
        
      
        
        
        House notes
        
        
          
          
        • The PC has 24 slots. If the Vita uses a higher slot, the file is still generated, but the PC may not show it.
          • 
          
        • Saves from PC version 1.0 have 3 fewer values at the end; they get padded with 0.
          • 
          
        • Settings (volume, display…) are not converted: each platform keeps its own.
          • 
          
        • If the converter says the [data] header is missing, your savefile.sav is encrypted: copy it again through Open decrypted.
